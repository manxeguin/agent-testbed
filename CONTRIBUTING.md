# Contributing

Thanks for your interest in contributing to `agent-testbed`!

## Getting started

1. Fork the repository and clone your fork.
2. Create a new branch for your change:
   ```sh
   git checkout -b my-change
   ```
3. Make your changes in small, focused commits.
4. Push your branch and open a pull request against `main`.

## Commit messages

- Use the present tense ("Add feature", not "Added feature").
- Keep the subject line under 72 characters.
- Reference related issues when applicable (e.g. `Fix #123`).

## Pull requests

- Keep PRs focused on a single change.
- Update or add tests where it makes sense.
- Make sure existing checks pass before requesting review.
- Respond to review feedback promptly.

## Reporting issues

When opening an issue, please include:

- A clear, descriptive title.
- Steps to reproduce the problem.
- Expected and actual behavior.
- Relevant environment details (OS, language/runtime version, etc.).

## Code of conduct

By participating, you agree to abide by a basic standard of respect and
professionalism. Be considerate, assume good faith, and help keep the
community welcoming for everyone.
